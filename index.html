iPhone Safari 安装指引

推荐使用免费的开源 Safari 扩展 Userscripts。安装脚本前，先启用该扩展。

1

安装 Safari 扩展

从 App Store 安装 Userscripts，打开一次 App 完成初始化。

2

允许 Safari 扩展

在 iPhone「设置 → App → Safari → 扩展」启用 Userscripts，并允许它访问小红书网站。

3

安装 Red Web 脚本

在 Safari 中打开下面的 .user.js 地址，打开 Safari 的扩展菜单，选择 Userscripts 并确认安装。

打开安装脚本 ↗

如安装页未加载：备用源地址。

4

访问官方小红书

在 Safari 打开 rednote.com 或 xiaohongshu.com/explore，点击顶部右侧或底部「登录」。两个域名与不同设备的登录状态需分别确认；若只出现「热门笔记」，可请求桌面网站。

v0.4.0 调试版：顶部和底部直接提供登录入口，登录后自动切换为「我」；刷新优先使用官网原生控件，增加防重复触发、超时恢复和下拉手势修复。同时支持 rednote.com，请在 Userscripts 中替换旧脚本并允许当前域名访问。已通过 Node 回归及手机宽度模拟检查；真实 iPhone Safari 仍需在设备上确认。

常见问题

怎么查看错误和复制报告？

安装 v0.4.0 并打开小红书官网后，点右下角半透明「调试」按钮。可以查看原生笔记链接数量、视觉卡片识别情况、匿名媒体尺寸、官网登录入口数量及页面异常。点击「复制报告」后发送至 GitHub Issues。报告不自动上传；发送前请再次检查是否含敏感信息。

登录为什么仍然打不开？

先点顶部右侧或底部「登录」，脚本会点击官网原生按钮；登录后自动显示「我」。如果手机页只有「热门笔记」而无原生入口，请在 Safari 中选择「请求桌面网站」，或在指引中选择 rednote 官网。电脑 Chrome 的登录不会自动同步到手机 Safari，两个官网域名的登录状态也需分别确认。

为什么刷新后没有新帖子？

新版会触发官网的原生刷新控件；加载期间按钮暂时禁用，只有收到新笔记才提示更新，12 秒无新内容会恢复按钮。若当前是固定的「热门笔记」手机展示页，请请求桌面网站或使用 rednote 官网，再确认登录。

打开官网后没有变化？

检查 Safari 的 Userscripts 扩展已启用且对当前小红书或 rednote 域名允许访问；确认脚本已激活。尝试请求桌面网站并刷新。若当前官网限制移动端页面，脚本无法强制开放被限制的功能。

怎样关闭或恢复官方原版？

点击脚本页面左上角菜单 →「切换原版」。如按钮不可用，直接在 Userscripts 扩展中禁用 Red Web。重新开启时，可打开 恢复脚本链接。

账号密码会上传到 GitHub 或开发者服务器吗？

不会。脚本在小红书网站的浏览器页面内运行，不需要私有代理、自己的服务器或额外的账号凭证；本仓库也没有登录收集端点。小红书官网本身会按其政策处理账号数据。

可以放到 iPhone 主屏幕吗？

Safari 的「共享 → 添加到主屏幕」可创建快捷方式。不过 iOS 独立网页 App 中是否运行 Safari Userscripts 扩展取决于系统支持；推荐直接在 Safari 中使用。

评论、视频、作者主页打不开怎么办？

第一版采用官方页面原生交互。可能是官网页面更新、账号未登录、移动端限制或风控。请在 GitHub Issues 附上问题描述和截图（请隐藏个人信息）。
